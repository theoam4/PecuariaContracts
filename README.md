# PecuariaContracts

Smart contract repository for the **Livestock** ecosystem, developed in Solidity using Foundry. It contains contracts designed to complement the livestock management system without turning the blockchain into an operational database or compromising the Flet application's *offline-first* functionality.

The contracts are consumed exclusively by authorized back-end services. The application continues to operate using a local SQLite database synchronized with an API; any blockchain integration occurs asynchronously, following event processing on the server.

## Contracts

### PecuariaIntegrityRegistry

The repository's initial contract, designed to ensure the integrity of events accepted by the server. It stores only the `recordId`, `payloadHash`, registration timestamp, and the address of the responsible wallet. Data regarding animals, farms, users, locations, and operational details remains *off-chain* (outside the blockchain).

Integration flow:

```text
Local SQLite → FastAPI API → PostgreSQL/outbox → worker → PecuariaIntegrityRegistry
```

Additional contracts may be included here as needed, provided they align with privacy requirements, business rules, and the *offline-first* architecture.

## Deploying the Integrity Registry locally

```bash
export INTEGRITY_REGISTRAR_ADDRESS=<worker-address>
forge script script/DeployPecuariaIntegrityRegistry.s.sol:DeployPecuariaIntegrityRegistry \
--rpc-url http://127.0.0.1:8545 --broadcast --private-key <development-key>
```

After deployment, use the returned address and the ABI generated by the `forge build` command in the Python worker's variables. Never include private keys in version control.

## Foundry

**Foundry is a blazing fast, portable and modular toolkit for Ethereum application development written in Rust.**

Foundry consists of:

- **Forge**: Ethereum testing framework (like Truffle, Hardhat and DappTools).
- **Cast**: Swiss army knife for interacting with EVM smart contracts, sending transactions and getting chain data.
- **Anvil**: Local Ethereum node, akin to Ganache, Hardhat Network.
- **Chisel**: Fast, utilitarian, and verbose solidity REPL.
